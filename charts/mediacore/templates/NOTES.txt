microphone to:
{{ if .Values.sfu.advertise.fromNodeIP }}
  the node's own address (status.hostIP), on udp/{{ .Values.sfu.ports.media }}
{{- end }}
{{- range .Values.sfu.advertise.addresses }}
  {{ . }}{{ if not (regexMatch ":[0-9]+$" (toString .)) }}, on udp/{{ $.Values.sfu.ports.media }}{{ end }}
{{- end }}

Check that visitors can reach it, and that udp/{{ .Values.sfu.ports.media }} is open to them in the
node firewall and in any cloud security group -- as UDP; a TCP rule for that
port does nothing at all. What the server settled on is in its own log:

  kubectl logs -n {{ .Release.Namespace }} deploy/{{ include "mediacore.sfu.fullname" . }} | grep "media transport ready"

If people join, the participant list is right, and nobody hears anything, that
line and the firewall are the two places to look. Nothing is logged as an error.

udp/{{ .Values.sfu.ports.media }} still goes straight to the node, so sfu.hostNetwork and the advertised

The signalling WebSocket needs an idle timeout longer than the quiet stretches
of a call. The chart ships the two ingress-nginx annotations for it; on any
other controller set that controller's own equivalent, or everyone is dropped
about a minute in with nothing in any log:

  kubectl get ingress -n {{ .Release.Namespace }} {{ include "mediacore.fullname" . }}-ingress -o jsonpath='{.metadata.annotations}'
{{- end }}
